# Build order for the prototype?

Type: grilling
Status: resolved
Blocked by: (none)

Three control schemes to build plus track, rules, cars, camera. What order?

## Answer

Resolved 2026-10-05:

1. **Slingshot vertical slice first** — simplest, works on desktop and
   phone, unblocks testing all non-control aspects; the control group for
   the experiments.
2. **Push-the-phone** once the basic game is working — main bet, tested
   early enough to fail or win fast.
3. **Flick** much later, a "maybe" option only.
